# შემოქმედი შალე

შემოქმედში მდებარე საოჯახო დასასვენებელი სივრცის ქართულენოვანი, ერთგვერდიანი საიტი. პირველი ეტაპი მოიცავს ორ კოტეჯს, დასვენებისა და შეკრებების აღწერას, გალერეას, მფლობელის, მდებარეობისა და კონტაქტის სექციებს.

პროექტი ადგილობრივად გასაშვებადაა მომზადებული. დაჯავშნა, გადახდა, ადმინისტრირება და გამოქვეყნება ამ ეტაპში არ შედის.

## ტექნოლოგიები

- Next.js 16.4.3, App Router და `src/` სტრუქტურა.
- React 19.3, TypeScript მკაცრი ტიპიზაციით.
- Tailwind CSS 4 და ფერების/ზომების CSS ცვლადები.
- ადგილობრივად მიწოდებული Noto Sans Georgian, 400 და 600 სისქით. შრიფტის ლიცენზია თან ახლავს `@fontsource/noto-sans-georgian` პაკეტს.
- Server Components; ბრაუზერში ინტერაქტიულია მხოლოდ მობილური მენიუ.

შექმნის გარემო: macOS 13.7.8 (Intel), Node.js 24.21.0, npm 11.19.0. გამოიყენეთ Node.js 24 LTS. საწყისი ფაილები შეიქმნა ოფიციალური `create-next-app` ხელსაწყოთი. ქართული საქაღალდის სახელის გამო შაბლონი შეიქმნა დროებით საქაღალდეში და გადმოტანილია პირდაპირ პროექტის ძირითად საქაღალდეში.

## გაშვება

VS Code-ში გახსენით ეს საქაღალდე. მენიუდან აირჩიეთ Terminal → New Terminal.

პირველი დაყენებისას ან პროექტის სხვა კომპიუტერზე გადატანისას:

```bash
npm ci
```

განვითარების სერვერის ჩასართავად:

```bash
npm run dev
```

ბრაუზერში გახსენით **http://localhost:3000**. თუ პორტი დაკავებულია, ტერმინალი სხვა მისამართს გამოგიტანთ. გასაჩერებლად ტერმინალში დააჭირეთ `Ctrl+C`.

დაინახავთ მწვანე მთავარ ეკრანს, ქართულ ნავიგაციას, ორ კოტეჯს და ქვემოთ ყველა სექციას. მონიშნული ვიზუალური ადგილები ფოტოების მოლოდინშია; არააქტიური კონტაქტების ქვეშ წერია „მალე დაემატება“.

## ტექსტები და ინფორმაცია

ყველა ბიზნესმონაცემი და ძირითადი ტექსტი თავმოყრილია **`src/data/site.ts`**-ში:

- `site.hero`, `site.about` — მთავარი სათაური, აღწერა და შესავალი.
- `site.cottages` — ზუსტად ორი კოტეჯი. აღწერა, დეტალები და ფოტოები ჯერ `null`-ია.
- `site.occasions`, `site.gallery` — ღონისძიებების ტექსტები და გალერეის ელემენტები.
- `site.owner` — მფლობელის სახელი, ბიოგრაფია და ფოტო.
- `site.contacts` — საკონტაქტო ინფორმაცია.
- `site.location` — რუკის ბმული ან დადასტურებული კოორდინატები.
- `copy` — სექციების სათაურები და დაუმატებელი ინფორმაციის წარწერები. ნამდვილი კონტაქტების/მდებარეობის დამატებისას განაახლეთ შესაბამისი „მალე დაემატება“ ტექსტებიც.

ტიპები წერია `src/types/site.ts`-ში. დაუდასტურებელი ინფორმაცია დატოვეთ `null`; გამოგონილი მონაცემები არ ჩაწეროთ.

## ფოტოები

რეალური ფოტოები შეინახეთ **`public/images/`**-ში. სახელებისა და ჩასმის მაგალითი მოცემულია ამ საქაღალდის `README.md` ფაილში. ჯერ შეინახეთ რეალური ფოტო, შემდეგ მიუთითეთ მისი მისამართი `src/data/site.ts`-ში.

მთავარი ფოტო განკუთვნილია დრონით გადაღებული ფართო კადრისთვის. გამოსახულებას ავტომატურად ემატება ტექსტის წაკითხვისთვის საჭირო მუქი ფენა. თითოეული ფოტო მხარს უჭერს `position` და `mobilePosition` პარამეტრებს.

## კონტაქტების დამატება

`site.contacts.facebook` და `site.contacts.instagram` შეავსეთ მხოლოდ ბიზნესის დადასტურებული სრული `https://` ბმულებით.

`phone` და `whatsappNumber` ცალ-ცალკე ივსება. მიუთითეთ საერთაშორისო ნომერი, რომელიც იწყება `+` ნიშნით და ქვეყნის კოდით. დასაშვებია გამოტოვებები, ფრჩხილები და ტირეები; საბოლოო ნომერს უნდა ჰქონდეს 8–15 ციფრი. ფორმატის შემოწმება არ ადასტურებს ნომრის მფლობელობას — გამოიყენეთ მხოლოდ ბიზნესის მიერ მოწოდებული ნომერი.

სწორი მონაცემის დამატების შემდეგ შესაბამისი ხატულა ავტომატურად იქცევა ბმულად. `null` ან არასწორად ჩაწერილი მონაცემი რჩება არააქტიური. WhatsApp-ის ბმული იქმნება მხოლოდ მისთვის ცალკე მითითებული სწორი ნომრიდან; ტელეფონის ნომერს ავტომატურად არ ვიყენებთ WhatsApp-ისთვის.

რუკისათვის მიუთითეთ `site.location.mapUrl` ან ზუსტი `coordinates`. დადასტურებული მონაცემი გაააქტიურებს რუკაზე გადასასვლელ ბმულს. ჩაშენებული ინტერაქტიული რუკისთვის ადგილი მომზადებულია; გარე რუკა ჯერ არ იტვირთება.

## სტრუქტურა და დიზაინი

- `src/app/page.tsx` — სექციების რიგი.
- `src/app/layout.tsx` — ქართული ენა, ლოკალური შრიფტი და მეტამონაცემები.
- `src/app/globals.css` — ადაპტური განლაგება, ვიზუალური სტილი და CSS ცვლადები.
- `src/components/layout/` — ზედა ნავიგაცია, მობილური მენიუ და ქვედა ნაწილი.
- `src/components/sections/` — თითოეული სექცია ცალკე კომპონენტად.
- `src/components/ui/` — განმეორებით გამოყენებადი სათაურები, ხატულები და ფოტოების ადგილები.
- `src/lib/contacts.ts` — ბმულებისა და ნომრების შემოწმება.

პალიტრა: თეთრი `#FFFFFF`, ტყის მწვანე `#153F32`, ღია მწვანე `#75A887`, თბილი ღია ფონი `#F4F5EF`. მობილურ ეკრანზე მენიუ იხსნება ღილაკით, იხურება Escape-ით, გარეთ დაჭერით ან სექციის არჩევით. კლავიატურის ფოკუსი ხილულია; შემცირებული მოძრაობის პარამეტრი გამორთავს რბილ გადახვევას.

## შემოწმება

```bash
npm run lint
npx tsc --noEmit
npm run build
```

აწყობილი ვერსიის გაშვება:

```bash
npm start
```

ბრაუზერული შემოწმების შედეგები იხილეთ [QA.md](QA.md)-ში. დიზაინის ნიმუშები: [დესკტოპი](docs/preview-desktop.png), [მობილური](docs/preview-mobile.png). რეალური ფოტოების ან ახალი ტექსტების დამატების შემდეგ კვლავ შეამოწმეთ მობილური და დიდი ეკრანი.

## ჯერ მოსაწოდებელია

- დრონით გადაღებული მთავარი ფოტო და სივრცის ფოტო.
- ორივე კოტეჯის ფოტოები, აღწერები და დადასტურებული დეტალები.
- გალერეის ფოტოები.
- მფლობელის სახელი, ბიოგრაფია და პორტრეტი.
- Facebook, Instagram, WhatsApp და ტელეფონი.
- ზუსტი მისამართი ან რუკის მდებარეობა.

რეალური დომენისა და გაზიარების ფოტოს გარეშე canonical URL და სოციალური ფოტომეტამონაცემები არ არის დამატებული. ასაკობრივი შეზღუდვა, ფასები, ტევადობა, სერვისები და შეფასებები არ არის გამოგონილი.
