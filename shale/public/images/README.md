# ფოტოები

ამ საქაღალდეში შეინახეთ მხოლოდ შემოქმედი შალეს ნამდვილი, გამოყენებისთვის ნებადართული ფოტოები.

რეკომენდებული სახელები:

- `hero-aerial.webp` — შალეს ხედი დრონიდან; ფართო კადრი.
- `about.webp` — სივრცის საერთო ფოტო.
- `cottage-01.webp`, `cottage-02.webp` — კოტეჯები.
- `gallery-01.webp` და შემდეგი ნომრები — გალერეა.
- `owner.webp` — მფლობელის პორტრეტი.

ეს სახელები მხოლოდ გზამკვლევია; სურათები ჯერ არ არის დამატებული. სანამ რეალური ფაილი აქ არ შეინახება, `src/data/site.ts`-ში შესაბამისი `image` დატოვეთ `null`.

ფაილის შენახვის შემდეგ `image` შეცვალეთ ობიექტით, მაგალითად:

```ts
image: {
  src: "/images/cottage-01.webp",
  alt: "აქ დაწერეთ კონკრეტული ფოტოს მოკლე, ზუსტი აღწერა",
  position: "center",
  mobilePosition: "center",
}
```

შეგიძლიათ გამოიყენოთ `.jpg`, `.png` და `.webp`. `position` და `mobilePosition` მართავს კადრის მოჭრას დიდ და პატარა ეკრანზე. ფოტოები ავტომატურად გამოისახება `next/image`-ით; მთავარ ფოტოს აქვს წინასწარი ჩატვირთვა, დანარჩენებს — საჭიროების მიხედვით ჩატვირთვა. ცარიელი ადგილების წარწერები ფოტოს დამატების შემდეგ ავტომატურად ქრება.
